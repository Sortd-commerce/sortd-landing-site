# Sortd

Landing page for Sortd, a food standard that lists only what passes independent checks.

The page follows the Sortd Figma frames: desktop landing, mobile landing, and the ingredient-ban cards.

Colors and type were measured from the desktop frame export: ink `#143503`, body `#2E4A22`, leaf `#4A7A2E`, sky `#D3E5F3`, cream `#FFF2E6`. The hero is about 76px on a desktop frame, section titles about 64px, and body copy about 18px.

Set `NEXT_PUBLIC_SITE_URL` when the public domain is ready. It defaults to `https://sortd.com` for canonical and Open Graph URLs.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s on the page

- Hero, standards ticker, and the three ways Sortd chooses food
- The four gates a product has to pass
- Seventeen categories on the shelf
- What Sortd bans, and why
- Side-by-side calls on the same product
- Closing line and footer
